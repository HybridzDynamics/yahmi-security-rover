# Yahmi Security Rover - Mobile App

The cross-platform mobile client for the Yahmi Security Rover surveillance and patrol system, built with Flutter.

---

## 📱 Features

- **Virtual Joystick**: Low-latency dual-axis motor control.
- **Live Stream Viewer**: Ultra-low latency camera feed with pan/tilt gimbal controls.
- **Telemetry HUD**: Real-time battery indicator, speed gauge, and obstacle distance warning.
- **Emergency Stop**: Hardware interrupt trigger for instant rover halt.
- **Alert Notifications**: Immediate push notifications when perimeter alerts are tripped.

---

## 🚀 Getting Started

### Prerequisites
- Flutter SDK 3.10+
- Dart SDK 3.0+
- Android Studio / Xcode

### Setup & Run
```bash
cd flutter_app

# Install packages
flutter pub get

# Run on connected device or simulator
flutter run
```

### Running Tests
```bash
flutter test
```
